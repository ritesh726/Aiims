📄 PDF to CBT Generator

Upload a question paper PDF, optionally upload its answer-key PDF, review every extracted question, correct any OCR mistakes, then generate a CBT HTML file. Parsing is automatic where the PDF layout is recognizable; always verify before publishing.

Important: PDF text extraction cannot reliably preserve every diagram, equation, column layout or scanned image. Scanned PDFs can use OCR, but OCR can make mistakes. The preview and answer-key review are mandatory before export.

1. Test settings & PDF upload

2. Review & edit extracted questions

Check question text, all four options and the correct answer. A question without a verified answer key cannot be exported as a scored CBT. Use the subject field to label Physics, Chemistry or Biology.

3. What “Publish” means

“Save draft” is only for this browser/device. To make the test available to every student on Vercel, download the generated HTML, upload that file into your GitHub repository, add its link to index.html, and redeploy. Student attempt history syncs to Supabase only when the Supabase setup is active and the student signs in.

PDF page images/diagrams are captured and embedded into the CBT. For each question, select the page containing its diagram or upload a cropped image; verify that the selected image matches the question. Do not publish a test until the questions and answer key have been checked.
